Five minutes, then it looks after itself

Three steps, the second is optional, and the third is opening a web page. After that, the dashboard is the only thing doing any work.

  1. 1Paste a calendar link

  2. 2Name the people and the chores

    Optional. Names and birthdays become the countdowns. Each chore passes to the next person every day, so nobody has to arbitrate whose turn it is.

  3. 3Open it on a screen

    Your dashboard has its own link. Open it in any browser — an old tablet, the TV, a monitor on the counter — and leave the screen on.

It is a link, not a login: nothing to sign in to on the screen, and nothing to install on it. Every morning the dashboard rebuilds itself. The agenda comes from your calendars. For makers

Here’s what “You host it” actually involves: the same repository, on your own machine, free for ever.

DinkyDash has been open source since 2021 and self-hosting is not a demo of it — it is the same code the hosted version runs, in single-family mode. You can have the real dashboard on your own machine in about two minutes, with no API key and nothing to pay for:

git clone https://github.com/caspii/dinkydash.git
cd dinkydash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
python sample_board.py && python app.py

That serves the dashboard on localhost:5000, with an invented family and a canned daily line. Add your own calendar links from /settings, and an Anthropic key when you want the real one — it runs once a day and costs well under a dollar a month.

What to know before you do

Setup on a Raspberry Pi is an afternoon rather than five minutes: systemd, kiosk mode, a screen schedule. There is no login — the dashboard and the settings page are both served without authentication, on the assumption they sit on your home network like a printer, so keep the port off the public internet. And self-hosting is community-supported: issues and pull requests are welcome, but there is no support commitment.
