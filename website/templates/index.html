What's on the board

One page, readable from the other side of the kitchen. The agenda, the rota, the countdowns, and one written line. The important things, and nothing else.

  • Today's agenda, in time order, merged from as many calendars as you connect.
  • A look at tomorrow underneath it, on the days today leaves room.
  • Whose turn each chore is — rotated daily, so nobody has to arbitrate.
  • Countdowns to birthdays and the dates children ask about on repeat.
  • One line written each morning — some days a fact, some days about the dog.
  • Light or dark, sized in one measurement so it fits every screen you own.

Nothing to maintain

Every family organiser dies the same way. Somebody sets it up in January, and by March nobody is ticking the boxes. So the board has no boxes.

Chores rotate on the date

Nobody marks one done, and nobody arbitrates whose turn it is. The wall already said, and it will still be saying the right name in March.

Countdowns count themselves

Ages and days-to-go are worked out fresh from today's date, so they cannot drift. Try the birthday countdown →

A bad morning stays honest

If the overnight run fails, the times, turns and countdowns are still today's. Only the written line is old, and the board tells you so.

The rest of the category is running the other way — tap-to-complete, points, rewards, child locks. Those are apps on a wall, and apps on a wall need feeding. This is a poster that updates itself.

Set up once, from your phone

Describe your family — names, birthdays, pets, chores, the dates you count down to — and paste in a calendar link or three. Then leave it alone.

  • Add people, pets, chores and countdowns
  • Connect Google, iCloud or Outlook calendars
  • See at a glance whether today's board is written
  • Rewrite the day's line whenever you like

Save the settings page to your home screen and it opens like an app. Every morning after that, the board rebuilds itself and the screen on the wall refreshes on its own.

Common questions

What happens to my board if DinkyDash goes away?

If you self-host, nothing happens: the code is MIT-licensed and already on your machine, so it keeps running whether this project continues or not. If we are hosting it for you, the same code is public, and your config is a small file you can export and run yourself. That is the point of building it this way.

Will features I have today ever move behind a paywall?

Not for anything already released. Everything on the board today is published under the MIT license, and that grant cannot be withdrawn for code that is already out — so a copy you are running stays yours to run. The hosted version is a convenience: we run the machine and pay the AI bill. It is not a key to features you would otherwise lose.

When can I get the hosted version?

It is being built now, in the open. Families are invited from the waiting list in small batches, so that what breaks for the first group is fixed before the next one arrives. Join the list and you will hear from us before it opens to everyone.

What will the hosted version cost?

$39 a year, or $6 a month, with a 14-day trial and no card up front. The first 100 families on the waiting list pay $29 a year, locked in for as long as they stay subscribed.

What screens can I use?

Anything with a web browser: an old iPad or Android tablet, a smart TV, a Raspberry Pi with a touchscreen, a spare monitor, or a laptop on the counter. The board measures the screen it lands on and sizes itself to be read from across the room.

Can I still run it myself for free?

Yes, and that will not change. DinkyDash is open source under the MIT license, and the hosted version is built from the same repository. If you are comfortable copying commands into a terminal, the setup guide takes about an afternoon and costs well under a dollar a month in AI usage. Self-hosting is community-supported.

Does it work with Google, Apple and Outlook calendars?

Yes, all three. Google Calendar, Apple iCloud Calendar and Outlook each let you share a calendar as an iCal link, and that link is what DinkyDash reads. You paste the link in — there is no sign-in to grant and no app to install. Connect several and they are merged into one agenda in time order. The setup guide has the steps for each one.

What happens to my family's calendar?

Your events are read to build the day's agenda, and that agenda is sent to Anthropic so Claude can write the day's line. Nothing is sold, and there are no adverts. Self-hosting keeps everything else on your own machine, and the board still runs with no API key at all — you simply go without the written line.

How is this different from a Skylight or Hearth?

Skylight and Hearth sell you a dedicated touchscreen, from $329.99 to $699, with a subscription on top that is optional at Skylight and required at Hearth. DinkyDash is just the software, running on a screen you already own, and nothing on it can be taken away later. It also does something they don't: a line written fresh every morning from your actual day. See the full comparison.
